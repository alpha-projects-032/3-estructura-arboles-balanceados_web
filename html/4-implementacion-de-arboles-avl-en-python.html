Implementación de árboles AVL en Python

Construir un árbol AVL funcional mediante clases, inserción, rotaciones, búsqueda, eliminación y recorridos.

Introducción

Los árboles AVL combinan la propiedad de ordenamiento de un árbol binario de búsqueda con reglas que limitan su altura. Para ello, calculan factores de equilibrio y, después de insertar o eliminar nodos, pueden aplicar rotaciones.

Desarrollaremos la implementación en Python 3 de manera progresiva: primero los nodos y la clase administradora; después los métodos auxiliares, inserción, rotaciones, búsqueda, eliminación y representación en terminal. Al final se presenta un programa completo que integra todas las piezas.

4.1 Creación de la clase Node

Cada nodo almacena su valor, dos referencias a posibles hijos y su altura. En este material, un subárbol vacío tiene altura −1 y una hoja tiene altura 0.

Atributo Función
value Valor o clave almacenada
left Referencia al hijo izquierdo
right Referencia al hijo derecho
height Altura del nodo, necesaria para calcular el equilibrio 
class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
        self.height = 0

Al crear Node(50), el nodo tiene altura cero y ambos hijos están vacíos (None).

node = Node(50)
print("Valor:", node.value)
print("Altura:", node.height)
print("Hijo izquierdo:", node.left)
print("Hijo derecho:", node.right)

Salida esperada

Valor: 50
Altura: 0
Hijo izquierdo: None
Hijo derecho: None

La clase AVLTree administra la raíz y las operaciones sobre el árbol. El atributo root comienza con el valor None.

class AVLTree:

4.3 Inserción de nodos y actualización de alturas

La inserción respeta primero el orden de búsqueda: valores menores a la izquierda y valores mayores a la derecha. En esta implementación no se agregan valores duplicados.

  1. Comparar el valor con el nodo actual.
  2. Descender recursivamente por la izquierda o la derecha.
  3. Crear el nuevo nodo cuando se encuentra una posición vacía.
  4. Actualizar alturas desde el punto de inserción hacia la raíz.
  5. Corregir posibles desequilibrios con las rotaciones apropiadas.

Métodos auxiliares de altura y equilibrio

def _height(self, node):
    if node is None:
        return -1
    return node.height

def _update_height(self, node):
    node.height = 1 + max(
        self._height(node.left),
        self._height(node.right)
    )

def _balance_factor(self, node):
    return self._height(node.left) - self._height(node.right)

La altura se actualiza mediante h(n) = 1 + max(h(izquierdo), h(derecho)). El factor de equilibrio se calcula como FE = h(izquierdo) − h(derecho). Los valores permitidos son −1, 0 y +1.

4.4 Implementación de rotaciones en Python

Las rotaciones cambian las referencias entre nodos sin perder el orden de búsqueda. Una rotación a la derecha reubica al hijo izquierdo; la rotación a la izquierda hace el movimiento opuesto.

Rotaciones simples

def _rotate_right(self, y):
    x = y.left
    transfer = x.right
    x.right = y
    y.left = transfer
    self._update_height(y)
    self._update_height(x)
    return x

def _rotate_left(self, x):
    y = x.right
    transfer = y.left
    y.left = x
    x.right = transfer
    self._update_height(x)
    self._update_height(y)
    return y

En ambas rotaciones se actualiza primero la altura del nodo que desciende y luego la del nodo que asciende.

Selección de los cuatro casos: LL, RR, LR y RL

def _rebalance(self, node):
    self._update_height(node)
    balance = self._balance_factor(node)

    if balance > 1:
        if self._balance_factor(node.left) < 0:
            node.left = self._rotate_left(node.left)
        return self._rotate_right(node)

    if balance < -1:
        if self._balance_factor(node.right) > 0:
            node.right = self._rotate_right(node.right)
        return self._rotate_left(node)

    return node
Condición Acción
FE > 1, hijo izquierdo con FE ≥ 0 LL: rotación a la derecha
FE > 1, hijo izquierdo con FE < 0 LR: izquierda en el hijo y derecha en el nodo
FE < −1, hijo derecho con FE ≤ 0 RR: rotación a la izquierda
FE < −1, hijo derecho con FE > 0 RL: derecha en el hijo e izquierda en el nodo

Inserción recursiva con reequilibrado

def insert(self, value):
    self.root = self._insert(self.root, value)

def _insert(self, node, value):
    if node is None:
        return Node(value)
    if value < node.value:
        node.left = self._insert(node.left, value)
    elif value > node.value:
        node.right = self._insert(node.right, value)
    else:
        return node  # Sin valores duplicados
    return self._rebalance(node)
La función _insert() devuelve siempre la raíz actualizada del subárbol. Esto es fundamental porque una rotación puede sustituir su raíz.

4.5 Búsqueda y eliminación de elementos

La búsqueda aprovecha el orden de los nodos y no modifica el árbol. La eliminación conserva el orden y revisa el equilibrio durante el retorno de la recursión.

Búsqueda iterativa

def search(self, value):
    node = self.root
    while node is not None:
        if value == node.value:
            return True
        if value < node.value:
            node = node.left
        else:
            node = node.right
    return False
Tipo de nodo Procedimiento para eliminarlo
Sin hijos Eliminar el nodo directamente
Con un hijo Devolver su único hijo como sustituto
Con dos hijos Copiar el valor del sucesor en inorden y eliminar ese sucesor

Eliminación recursiva

def delete(self, value):
    self.root = self._delete(self.root, value)

def _delete(self, node, value):
    if node is None:
        return None
    if value < node.value:
        node.left = self._delete(node.left, value)
    elif value > node.value:
        node.right = self._delete(node.right, value)
    else:
        if node.left is None:
            return node.right
        if node.right is None:
            return node.left

        successor = node.right
        while successor.left is not None:
            successor = successor.left
        node.value = successor.value
        node.right = self._delete(node.right, successor.value)

    return self._rebalance(node)

Si el nodo tiene dos hijos, el sucesor en inorden es el menor valor del subárbol derecho. Una vez eliminado, _rebalance() actualiza y reequilibra los antepasados, si es necesario.

La búsqueda, inserción y eliminación tienen complejidad temporal O(log n) en el peor caso para un árbol AVL.

4.6 Recorrido y visualización del árbol AVL

El recorrido inorden visita el subárbol izquierdo, el nodo actual y el subárbol derecho. En un árbol binario de búsqueda con claves únicas, produce los valores en orden ascendente.

El método display() representa el árbol mediante sangrías. I indica hijo izquierdo; D, hijo derecho; h, altura; y FE, factor de equilibrio.

def inorder(self):
    result = []

    def visit(node):
        if node is None:
            return
        visit(node.left)
        result.append(node.value)
        visit(node.right)

    visit(self.root)
    return result

def display(self):
    def visit(node, level=0, prefix="Raíz: "):
        if node is None:
            return
        print(
            "    " * level + prefix + str(node.value)
            + f" (h={node.height}, FE={self._balance_factor(node)})"
        )
        visit(node.left, level + 1, "I: ")
        visit(node.right, level + 1, "D: ")

    if self.root is None:
        print("(árbol vacío)")
    else:
        visit(self.root)

Ejemplo práctico integrado en Python

Este programa integra todos los métodos anteriores. Es autónomo y ejecutable en Python 3, sin bibliotecas externas. Incluye inserción, búsqueda, eliminación y recorridos. Copia el bloque completo en un archivo avl.py.

class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
        self.height = 0

class AVLTree:
    def __init__(self):
        self.root = None
    def _height(self, node):
        if node is None:
            return -1
        return node.height

    def _update_height(self, node):
        node.height = 1 + max(
            self._height(node.left),
            self._height(node.right)
        )

    def _balance_factor(self, node):
        return self._height(node.left) - self._height(node.right)
    def _rotate_right(self, y):
        x = y.left
        transfer = x.right
        x.right = y
        y.left = transfer
        self._update_height(y)
        self._update_height(x)
        return x

    def _rotate_left(self, x):
        y = x.right
        transfer = y.left
        y.left = x
        x.right = transfer
        self._update_height(x)
        self._update_height(y)
        return y
    def _rebalance(self, node):
        self._update_height(node)
        balance = self._balance_factor(node)

        if balance > 1:
            if self._balance_factor(node.left) < 0:
                node.left = self._rotate_left(node.left)
            return self._rotate_right(node)

        if balance < -1:
            if self._balance_factor(node.right) > 0:
                node.right = self._rotate_right(node.right)
            return self._rotate_left(node)

        return node
    def insert(self, value):
        self.root = self._insert(self.root, value)

    def _insert(self, node, value):
        if node is None:
            return Node(value)
        if value < node.value:
            node.left = self._insert(node.left, value)
        elif value > node.value:
            node.right = self._insert(node.right, value)
        else:
            return node  # Sin valores duplicados
        return self._rebalance(node)
    def search(self, value):
        node = self.root
        while node is not None:
            if value == node.value:
                return True
            if value < node.value:
                node = node.left
            else:
                node = node.right
        return False
    def delete(self, value):
        self.root = self._delete(self.root, value)

    def _delete(self, node, value):
        if node is None:
            return None
        if value < node.value:
            node.left = self._delete(node.left, value)
        elif value > node.value:
            node.right = self._delete(node.right, value)
        else:
            if node.left is None:
                return node.right
            if node.right is None:
                return node.left

            successor = node.right
            while successor.left is not None:
                successor = successor.left
            node.value = successor.value
            node.right = self._delete(node.right, successor.value)

        return self._rebalance(node)
    def inorder(self):
        result = []

        def visit(node):
            if node is None:
                return
            visit(node.left)
            result.append(node.value)
            visit(node.right)

        visit(self.root)
        return result

    def display(self):

            if node is None:
                return

            print("(árbol vacío)")

            visit(self.root)

tree = AVLTree()
for value in [30, 20, 10, 40, 50, 25]:
    tree.insert(value)

print("Árbol después de insertar:")
tree.display()
print("Recorrido inorden:", tree.inorder())
print("Buscar 25:", tree.search(25))
print("Buscar 99:", tree.search(99))

tree.delete(20)
print("\nÁrbol después de eliminar 20:")
tree.display()
print("Recorrido final:", tree.inorder())

Actividad práctica: gestión de códigos de productos

Una aplicación de inventario necesita almacenar, consultar y eliminar códigos numéricos mediante un árbol AVL. Utiliza el programa completo como punto de partida.

  1. Crea un árbol AVL vacío.
  2. Inserta los códigos 45, 25, 65, 15, 35, 55, 75.
  3. Visualiza el árbol y comprueba los factores de equilibrio.
  4. Inserta 10, 5, 30 y observa si se producen rotaciones.
  5. Busca los códigos 35, 75 y 90.
  6. Elimina los códigos 25 y 65 en ese orden.
  7. Ejecuta el recorrido inorden y comprueba el orden ascendente.
  8. Explica cómo las rotaciones conservan el equilibrio de la estructura.

Criterios de verificación

  • El subárbol izquierdo contiene valores menores y el derecho, mayores.
  • Los valores duplicados no se almacenan.
  • Las alturas se actualizan tras las modificaciones.
  • Todos los nodos conservan factores de equilibrio entre −1 y +1.
  • Las búsquedas y eliminaciones son correctas.
  • El recorrido inorden contiene los valores esperados en orden ascendente.

Síntesis

La clase Node representa cada elemento; la clase AVLTree administra la estructura y sus operaciones. Las alturas y los factores de equilibrio indican cuándo se requiere una rotación.

La inserción y la eliminación combinan búsqueda ordenada, recursividad y reequilibrado. Los recorridos y la visualización permiten comprobar la estructura después de cada operación.

Los árboles AVL garantizan una altura O(log n), fundamento de la eficiencia de sus operaciones. El próximo subtema analizará sus aplicaciones y su rendimiento frente a otras estructuras.
