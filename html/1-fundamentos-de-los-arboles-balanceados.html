Fundamentos de los árboles balanceados

Comprender las condiciones de equilibrio, la altura y el factor de balanceo, y su relación con la eficiencia de las operaciones en árboles binarios de búsqueda.

Introducción

Los árboles son estructuras de datos no lineales que organizan la información jerárquicamente. Los árboles binarios de búsqueda (ABB) permiten localizar, insertar y eliminar elementos mediante relaciones de orden entre los nodos.

Sin embargo, ciertas secuencias de inserción provocan ramas demasiado largas y reducen la eficiencia de las operaciones. Los árboles balanceados utilizan reglas de equilibrio para limitar este problema.

En este subtema estudiaremos el concepto de balanceo, las diferencias entre estructuras, la altura, la profundidad y el factor de equilibrio. Posteriormente, estos fundamentos permitirán comprender los árboles AVL.

1.1 Concepto de árbol balanceado

Un árbol balanceado mantiene su altura dentro de límites establecidos por reglas de equilibrio para evitar que el crecimiento desigual perjudique significativamente las operaciones.

El balanceo no exige que todas las ramas tengan exactamente la misma cantidad de nodos. Exige cumplir condiciones específicas que limitan su crecimiento desigual.

Organización

Conserva la jerarquía y el orden de búsqueda entre los nodos.

Altura controlada

Reduce el riesgo de desarrollar ramas excesivamente profundas.

Reorganización

Algunos tipos utilizan rotaciones después de insertar o eliminar nodos.

Ejemplo: los valores 10, 20, 30, 40 y 50

ABB sin balanceo

Altura: 4 aristas. Buscar 50 requiere visitar 5 nodos.

ABB balanceado

Altura: 2 aristas. Buscar 50 requiere visitar 3 nodos.

La diferencia muestra cómo una altura menor puede reducir la cantidad de comparaciones necesarias durante una búsqueda.

1.2 Diferencias entre árboles binarios de búsqueda y árboles balanceados

Ambos conservan la propiedad de orden de un ABB: los valores menores se ubican en el subárbol izquierdo y los mayores en el derecho. En este ejemplo se consideran claves distintas; para duplicados, debe establecerse una política.

Característica ABB convencional ABB balanceado
Organización Jerárquica y ordenada Jerárquica y ordenada
Control de altura No garantizado Regulado por reglas de equilibrio
Inserción Mantiene el orden de búsqueda Mantiene el orden y puede realizar ajustes
Peor caso de búsqueda O(n) O(log n) en árboles AVL
Riesgo de degeneración Puede formar una cadena Sus reglas impiden una cadena lineal de altura n
Implementación Más sencilla Requiere lógica adicional
Caso: inventario de productos

Si miles de códigos se insertan de forma ascendente en un ABB convencional, la búsqueda puede requerir recorrer una gran cantidad de nodos. Un árbol AVL limita su altura, manteniendo un peor caso logarítmico.

1.3 Altura y profundidad de un árbol

Profundidad de un nodo

Número de aristas desde la raíz hasta ese nodo. La raíz tiene profundidad 0.

Altura de un nodo

Número de aristas en el camino descendente más largo hasta una hoja. Una hoja tiene altura 0.

Ejemplo visual

La altura del árbol es 2 aristas y su profundidad máxima también es 2.

Nodo Profundidad Altura
40 0 2
20 1 1
60 1 1
10, 30 y 70 2 0
En un ABB, el número máximo de nodos visitados en una búsqueda está limitado por la altura del árbol + 1, contando la raíz como primer nodo.

1.4 Factor de equilibrio y su importancia

En los árboles AVL, el factor de equilibrio mide la diferencia entre las alturas de los subárboles izquierdo y derecho de un nodo.

FE(n) = altura(izquierdo) − altura(derecho)

Convención: la altura de un subárbol vacío es −1.

+1Izquierdo una unidad más alto
0Alturas iguales
−1Derecho una unidad más alto

Cuando un nodo presenta un factor superior a +1 o inferior a −1, incumple la condición de equilibrio AVL. En ese caso, puede ser necesario reorganizar la estructura mediante rotaciones.

Ejemplo de cálculo

Nodo 40: altura izquierda = 1, altura derecha = 0. Por tanto, FE(40) = 1 − 0 = +1.

Nodo 20: altura izquierda = 0, altura derecha = −1. Por tanto, FE(20) = 0 − (−1) = +1.

En un árbol AVL se comprueba el factor de equilibrio de cada nodo, no solamente el de la raíz.

1.5 Ventajas del balanceo en la eficiencia de las operaciones

La altura de un árbol influye directamente en el trabajo necesario para localizar, insertar y eliminar elementos. Un árbol AVL conserva una altura O(log n) y proporciona garantías eficientes incluso en el peor caso.

Operación ABB convencional (peor caso) AVL (peor caso)
Búsqueda O(n) O(log n)
Inserción O(n) O(log n)
Eliminación O(n) O(log n)

La notación O(n) representa crecimiento lineal respecto a la cantidad de nodos. En cambio, O(log n) representa un crecimiento mucho más moderado conforme aumenta el conjunto de datos.

Búsquedas previsibles

Evita que una inserción ordenada convierta las búsquedas en recorridos lineales.

Crecimiento controlado

Mantiene una altura acotada aun cuando aumenta la cantidad de nodos.

Datos dinámicos

Admite inserciones y eliminaciones respetando sus condiciones de equilibrio.

Consideración técnica

El balanceo tiene un costo: las implementaciones AVL mantienen información adicional de altura o equilibrio y pueden necesitar rotaciones. Por ello, deben seleccionarse según los requisitos del programa.

Ejemplo introductorio en Python

Este ejemplo implementa un ABB convencional sin balanceo. Se insertan cinco valores en orden ascendente para observar su efecto en la altura.

class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None


def insert(root, value):
    if root is None:
        return Node(value)

    if value < root.value:
        root.left = insert(root.left, value)
    elif value > root.value:
        root.right = insert(root.right, value)

    return root


def height(root):
    if root is None:
        return -1

    return 1 + max(
        height(root.left),
        height(root.right)
    )


root = None

for value in [10, 20, 30, 40, 50]:
    root = insert(root, value)

print("Altura del árbol:", height(root))
Resultado esperado 
Altura del árbol: 4

Análisis del ejemplo

  • Node representa un nodo y las referencias a sus hijos.
  • insert() agrega valores siguiendo el orden del ABB; los duplicados se omiten.
  • height() calcula la altura recursivamente y asigna −1 a los subárboles vacíos.
  • Al insertar valores ascendentes, todos quedan a la derecha: por ello el árbol alcanza una altura de 4 aristas.
Importante: este código aún no implementa un árbol AVL. Su función es demostrar el problema que resolveremos mediante los mecanismos de balanceo.

Síntesis

Los árboles balanceados mantienen una altura controlada mediante reglas específicas, reduciendo el riesgo de un crecimiento excesivamente desigual.

La profundidad se mide desde la raíz hasta un nodo; la altura, desde un nodo hasta su hoja descendiente más lejana.

En los árboles AVL, el factor de equilibrio compara las alturas de los subárboles izquierdo y derecho. Los valores válidos para cada nodo son −1, 0 y +1.
