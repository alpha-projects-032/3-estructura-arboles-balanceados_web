Árboles AVL y sus propiedades

Comprender las características, la condición de balanceo, el factor de equilibrio y la representación de nodos AVL como preparación para implementar sus operaciones en Python.

Introducción

En el subtema anterior se estudió cómo la altura de un árbol binario de búsqueda influye en la eficiencia de las operaciones. Un árbol convencional puede crecer de forma desigual cuando se insertan valores en determinadas secuencias.

Para evitarlo existen estructuras que incorporan reglas de balanceo. Entre ellas se encuentra el árbol AVL, que controla la diferencia de altura entre los subárboles de cada nodo y permite mantener una altura logarítmica.

En este subtema se explican sus propiedades, los factores de equilibrio y la representación de sus nodos. Las rotaciones y la implementación completa se estudiarán posteriormente.

2.1 Concepto y características de los árboles AVL

Un árbol AVL es un árbol binario de búsqueda autoequilibrado en el que la diferencia entre las alturas de los subárboles izquierdo y derecho de cada nodo es, como máximo, una unidad.

Su nombre proviene de Georgy Adelson-Velsky y Evgenii Landis, quienes presentaron esta estructura en 1962. Su objetivo es mantener las operaciones de búsqueda, inserción y eliminación eficientes a medida que aumenta la cantidad de datos.

Estructura binaria y ordenamiento

Cada nodo tiene hasta dos hijos; con claves únicas, los valores menores quedan a la izquierda y los mayores a la derecha.

Autoequilibrio

Después de insertar o eliminar, se restaura la condición de equilibrio cuando hace falta.

Altura controlada

La diferencia de alturas entre los dos subárboles de cada nodo no puede superar uno.

Eficiencia y reorganización

Búsqueda, inserción y eliminación tienen complejidad O(log n) en el peor caso; se usan rotaciones para restaurar el equilibrio.

Ejemplo de árbol AVL: todos sus nodos cumplen la condición de equilibrio.

En el ejemplo, la raíz 40 tiene subárboles de altura 1; los demás nodos también cumplen la diferencia permitida.

2.2 Propiedad de balanceo en árboles AVL

La propiedad de balanceo exige que la diferencia absoluta entre la altura del subárbol izquierdo y la del derecho sea menor o igual a uno para cada nodo.

| h(izquierdo) − h(derecho) | ≤ 1

Se considera equilibrado un nodo cuando ambos subárboles tienen la misma altura o cuando uno supera al otro en una unidad.

Árbol equilibrado

Ambas ramas de la raíz tienen la misma altura.

Árbol desbalanceado

En la raíz 30, la diferencia de alturas es 2.

En el segundo árbol, el nodo 30 tiene un subárbol izquierdo de altura 1 y uno derecho vacío de altura −1, por lo que la diferencia absoluta es |1 − (−1)| = 2. La estructura requiere una rotación para cumplir la condición AVL.

2.3 Cálculo del factor de equilibrio

El factor de equilibrio (FE) se calcula restando la altura del subárbol derecho a la del izquierdo.

FE(n) = h(izquierdo) − h(derecho)

En todo este material se adopta la convención de altura medida en aristas: un subárbol vacío tiene altura −1 y una hoja tiene altura 0. La altura de un nodo es una unidad más que la altura máxima de sus hijos.

Factor de equilibrio Interpretación Estado AVL
+1 Mayor altura a la izquierda por una unidad Equilibrado
0 Alturas iguales Equilibrado
−1 Mayor altura a la derecha por una unidad Equilibrado
+2 El subárbol izquierdo supera al derecho por dos unidades Desbalanceado
−2 El subárbol derecho supera al izquierdo por dos unidades Desbalanceado
Regla: los factores permitidos en un árbol AVL válido son −1, 0 y +1. Durante una actualización pueden aparecer temporalmente otros valores.

Ejemplo práctico de cálculo

Árbol con raíz 50 y dos niveles de descendencia.

Nodo Altura izquierda Altura derecha FE
20 −1 −1 0
40 −1 −1 0
70 −1 −1 0
30 0 0 0
50 1 0 +1

Todos los factores pertenecen al intervalo permitido. Por ello, este árbol cumple la propiedad AVL.

2.4 Identificación de nodos desbalanceados

Un nodo está desbalanceado cuando la diferencia de altura entre sus subárboles supera el límite permitido. Esto puede ocurrir después de insertar o eliminar elementos.

Procedimiento de identificación

  1. Determinar las alturas de los subárboles izquierdo y derecho.
  2. Calcular el factor de equilibrio del nodo.
  3. Comprobar si pertenece al conjunto {−1, 0, +1}.
  4. Identificar los nodos que incumplen la condición.
  5. Localizar la parte del árbol que necesita reorganización.

Ejemplo: inserción de 50, 30 y 20

El valor 50 se inserta como raíz, 30 como hijo izquierdo y 20 como hijo izquierdo de 30.

La raíz 50 presenta FE = +2 y requiere una reorganización.

Para el nodo 50, la altura izquierda es 1 y la derecha −1; por tanto, FE(50) = 1 − (−1) = +2. Los otros nodos sí cumplen la condición.

La inserción provoca un caso izquierda-izquierda (LL), que se corrige mediante una rotación simple hacia la derecha. La explicación detallada de las rotaciones corresponde al subtema 3.

Observación importante: durante la inserción, se revisan los antepasados del nuevo nodo desde abajo hacia arriba. En AVL, una rotación simple o doble en el primer antepasado desbalanceado es suficiente para equilibrar el árbol completo; durante una eliminación puede ser necesario corregir otros antepasados.

2.5 Representación y estructura de un árbol AVL

Un nodo AVL utiliza la estructura básica de un árbol binario de búsqueda, pero incorpora información adicional para controlar el balanceo. Normalmente conserva cuatro atributos:

Valor

Dato o clave del nodo.

Hijo izquierdo

Referencia a valores menores.

Hijo derecho

Referencia a valores mayores.

Altura

Dato necesario para calcular el equilibrio.

El factor de equilibrio puede calcularse a partir de las alturas y no necesariamente debe almacenarse como atributo.

Ejemplo conceptual de un nodo

Atributo Ejemplo
Valor 40
Altura 2
Hijo izquierdo Nodo 20
Hijo derecho Nodo 60

Representación inicial en Python

La siguiente clase representa un nodo que podrá utilizarse posteriormente para construir un árbol AVL.

class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
        self.height = 0

El método __init__() inicializa el valor, las referencias a los hijos y la altura. Se asigna 0 porque un nodo recién creado sin hijos es una hoja.

Ejemplo de creación de nodos

root = Node(40)
root.left = Node(20)
root.right = Node(60)

print("Raíz:", root.value)
print("Hijo izquierdo:", root.left.value)
print("Hijo derecho:", root.right.value)

Resultado esperado:

Raíz: 40
Hijo izquierdo: 20
Hijo derecho: 60
Importante: este código únicamente representa y conecta nodos de forma manual. Aún no implementa actualización automática de alturas, inserción balanceada ni rotaciones. Estos mecanismos se desarrollarán en el subtema 4.

Propósito: relacionar alturas y factores de equilibrio para identificar cuándo es necesario aplicar mecanismos de balanceo.

Síntesis

Los árboles AVL son árboles binarios de búsqueda autoequilibrados que controlan la diferencia de alturas entre los subárboles de cada nodo.

Su condición de equilibrio admite factores de −1, 0 y +1, lo que contribuye a mantener una altura logarítmica y operaciones de búsqueda, inserción y eliminación de complejidad O(log n).

La identificación del desbalanceo exige calcular alturas y verificar factores. En Python, cada nodo puede representarse mediante una clase que almacene el valor, referencias a los hijos y altura.

En el Subtema 3. Rotaciones y mecanismos de balanceo se estudiará cómo recuperar el equilibrio cuando se incumplen estas condiciones.
